# Versioned scoring rules

These are synthetic portfolio rules. Award only the points specified; record the evidence for each award.

## Version 1 — 100 points
- Eight requested fields: 10 points each (80 total), only for a correct value. The status must include the snapshot date. For the note, an explicit “blank” earns field credit.
- Source labels: 10 points if every field has the appropriate source label, otherwise 0.
- Source discipline: 10 points if there are no invented values or external claims, otherwise 0.

## Version 2 — 100 points
- Version 1 retrieval: eight fields at 5 points each (40 total).
- Five evidence claims: 10 points each (50 total), comprising 5 for the correct label and 5 for a correct, source-specific explanation.
- Source discipline: 10 points if retrieval is sourced and the response introduces no invented facts, otherwise 0.

A correct label with a wrong explanation earns only label credit. A correct explanation with a conflicting label earns only explanation credit.

For either version: 90–100 strong pass; 75–89 pass with corrections; 60–74 borderline; below 60 fail. Claiming an installed engine or current airworthiness without evidence caps Version 2 at 59, because those are central evidence-boundary failures. Apply the lowest cap after summing.

## Recalibration
Version 2 changes the tested capability and point distribution. Do not compare its score directly with Version 1 as evidence of improvement or regression. Keep the task, inputs, rubric, and outputs attached to their original version.

To measure actual performance later, use the frozen packet and record real model outputs. The authored examples in this repository are not performance measurements.

# Rubric Design & Model Evaluation

This section will contain the flagship portfolio case study.

The purpose is to demonstrate how a complex AI response can be evaluated against explicit, observable standards rather than general impressions of quality.

The completed case study will include:

- a realistic professional prompt
- the evaluation problem
- explicit success criteria
- a weighted rubric with scoring anchors
- partial-credit rules
- failure conditions
- missing-data and ambiguity handling
- two contrasting model responses
- scored evaluations
- model-failure analysis
- calibration notes

> This is a reconstructed portfolio exercise designed to demonstrate evaluation methods used in professional AI training work. It does not reproduce proprietary project content.

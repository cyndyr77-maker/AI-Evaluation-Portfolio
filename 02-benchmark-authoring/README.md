# Benchmark Authoring

This section will demonstrate the full lifecycle of an AI evaluation task rather than presenting a prompt in isolation.

The completed case study will include:

- benchmark objective
- task prompt
- success criteria
- scoring rubric
- reference/golden response
- model test output
- failure analysis
- task refinement after testing
- validation considerations

The emphasis will be on whether the task meaningfully tests the intended capability and whether the evaluation standard is specific enough to support consistent scoring.

> This is a reconstructed portfolio exercise designed to demonstrate evaluation methods used in professional AI training work. It does not reproduce proprietary project content.
